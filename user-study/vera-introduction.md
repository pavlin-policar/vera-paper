## Using VERA for Static Explanations

_Visual Explanations via Region Annotation_ (VERA) is a novel technique developed by our laboratory for the explanations of point embeddings. VERA produces a set of visual explanations shown as panels, each of which aims to explain a particular region of the visualization.

In the following quizzes, you will be provided with at most 16 visual explanations generated by VERA for each of the following quizzes. The first eight of the explanations are descriptive and try to characterize interesting regions of the space. The remaining eight explanations will be contrastive and will show where in the visualization particular feature values occur.

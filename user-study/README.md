# Study Design

The user study comprises of six quizzes, each corresponding to one dataset.

Participants were randomly assigned into two groups. Both groups completed all six quizzes in the same order, but varied in the types of explanations they were allowed to use.
The first group completed the first set of quizzes using Orange, and the second set of quizzes using the provided VERA explanations. The second group completed the first set of quizzes using VERA explanations and the second set using Orange.
The exact study format is shown in the table below.

| Dataset | Group 1 | Group 2 |
|-|-|-|
| | Orange Introduction | VERA Introduction |
| Iris | *Orange* | *VERA explanations* |
| Employee Attrition | *Orange* | *VERA explanations* |
| Raisin | *Orange* | *VERA explanations* |
| | Orange Survey | VERA Survey |
| | VERA Introduction | Orange Introduction |
| Penguins | *VERA explanations* | *Orange* |
| Titanic | *VERA explanations* | *Orange* |
| Wine Quality | *VERA explanations* | *Orange* |
| | VERA Survey | Orange Survey |
| | Final Survey | Final Survey |
